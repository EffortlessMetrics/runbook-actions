# Default Profiles

Export two `.lp5` files from Logi Options+ and commit them here using these names:

| File                     | Device                  |
| ------------------------ | ----------------------- |
| `DefaultProfile70.lp5`  | MX Creative Keypad      |
| `DefaultProfile71.lp5`  | MX Creative Dialpad     |

These names are the SDK's expected convention. Exporting via the Options+ UI
is recommended over hand-editing.
